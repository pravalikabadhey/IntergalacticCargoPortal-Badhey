# IntergalacticCargoPortal — Badhey

Full-stack portal with Authentication and Role-Based Access Control (RBAC) for legacy cargo manifests.

**Stack:** Python (FastAPI) · SQLite · React (Vite) · JWT auth

## Repository layout

The project is developed across three feature branches, each in its own git worktree:

| Task | Branch | Worktree path |
|------|--------|---------------|
| Task 1 — Foundation (Auth & DB)  | `task-1-foundation`  | `..\worktrees\task-1-foundation\` |
| Task 2 — Core Engine (Uploads)   | `task-2-core-engine` | `..\worktrees\task-2-core-engine\` |
| Task 3 — Frontend Dashboard      | `task-3-frontend`    | `..\worktrees\task-3-frontend\` |

Local setup instructions will be added at the end of Task 3.
